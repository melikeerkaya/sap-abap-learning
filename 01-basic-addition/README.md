Basic Addition

Description

A simple ABAP application that adds two integer numbers and displays the result.

Concepts Used

CLASS and IMPLEMENTATION

INTERFACES

DATA declarations

Integer data type (TYPE I)

Variable assignment

Addition operator (+)

Console output using out->write( )

Example

Input:

First number: 100

Second number: 10

Output:

Sum: 110

Purpose

This project is part of my SAP ABAP learning journey.
