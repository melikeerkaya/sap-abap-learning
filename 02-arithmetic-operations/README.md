Arithmetic Operations

Description

A simple ABAP application that performs four basic mathematical operations on two integer numbers.

Operations

Addition (+)

Subtraction (-)

Multiplication (*)

Division (/)

Concepts Used

CLASS and IMPLEMENTATION

INTERFACES

DATA declarations

Integer data type (TYPE I)

Variable assignment

Arithmetic operators

CLEAR statement

String templates

Console output using out->write( )

Example

Input:

First number: 100

Second number: 10

Output:

Addition: 110

Subtraction: 90

Multiplication: 1000

Division: 10

Purpose

This project is part of my SAP ABAP learning journey. It demonstrates basic arithmetic operations and variable handling in ABAP.
